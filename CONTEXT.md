# Stox Project Context (`CONTEXT.md`)

> Read this file first in new or compacted sessions instead of scanning the repository broadly.

## 1. Safety & Architecture Invariants
- **Strictly Read-Only Advisory**: Never write, import, or execute `place_order`, `modify_order`, `cancel_order`, `order_margins`, or live trade execution (verified by regression tests in `tests/`).
- **Deterministic Engine**: All scores, technical levels, stop losses, intrinsic values, and verdicts are rule-based Python logic (no LLM in runtime analysis).
- **Privacy**: `storage/kite_token.json`, `storage/my_holdings.json`, credentials, and `.env*` files are gitignored and must never be committed.

## 2. Runtime Architecture & Ports
- **Backend API (`dashboard_server.py`)**: Stdlib `http.server` listening on `http://127.0.0.1:8765` (config: `DASHBOARD_HOST`, `DASHBOARD_PORT`).
  - Does **not** hot-reload Python code; always run `.\cleanup_server.ps1 -Restart` after backend edits.
  - Serves REST API (`/api/*`), markdown reports (`/reports/*`, `/news_reports/*`, `/news/*`), and returns 404 on `/` (legacy `static/index.html` is retired).
  - Does **not** implement `/ws`; the Angular client automatically falls back to 30s HTTP polling via `frontend/src/app/core/services/ws.service.ts`.
- **Alternate ASGI Server (`api/main.py`)**: Starlette + WebSocket (`/ws`) app sharing business logic in `api/services.py` and `api/routes.py`.
- **Frontend SPA (`frontend/`)**: Angular 22 dev server (`npm start` / `ng serve`) on `http://localhost:4200`, proxying `/api`, `/ws`, `/news_reports`, `/reports` to `http://localhost:8765` via `frontend/proxy.conf.json` (and `frontend/vite.config.ts`). Production build writes to `frontend/dist/stox/browser`.

## 3. Repository & Key File Map
### Configuration & Stock Universes
- `config.py`: Paths, worker counts, quote sources (`QUOTE_SOURCES`), and scheduler toggle (`AUTO_SCHEDULE`).
- `symbols.json`: Curated watchlist (**61** symbols; default `"curated"` universe).
- `symbols_midcap_250.json`: Top 250 Midcap & Emerging Growth universe (**250** symbols; `"midcap250"` universe).
- `symbols_nse_all.json`: Full NSE equity list (`"all_nse"` universe, generated by `tools/nse_universe.py`).
- `storage/cache.db`: SQLite database storing candles, quotes, agent run outputs, and fallback queue state.

### Backend Pipeline & Services
- `main.py`: CLI analysis runner (`--midcap-250`, `--all-nse`, `--symbols-file`, `--symbol`, `--force`, `--limit`).
- `run_analysis.ps1`: Interactive Windows runner (menu `[5]` runs Top 250 Mid Cap analysis with `symbols_midcap_250.json`).
- `graph.py`: Orchestrates agent execution.
- `agents/`: Rule-based agents (`historical_rag_agent.py`, `technical_agent.py`, `news_sentiment_agent.py`, `macro_agent.py`, `macro_sentinel.py`, `fundamental_agent.py`, `risk_agent.py`, `synthesizer_agent.py`).
- `tools/`: Data & quantitative engines (`historical_data_tools.py`, `tech_tools.py`, `pattern_engine.py`, `forensic_financial_engine.py`, `fundamental_tools.py`, `fundamental_picks.py`, `long_term_strategy.py`, `peer_benchmark_engine.py`, `quote_tools.py`, `kite_portfolio.py`, `market_scanner.py`, `events_tools.py`, `scheduler.py`, `web_security.py`, `outcome_tracker.py`).
- `api/services.py`: Shared data assembly (`_load_symbols_list(universe=...)`, `get_all_stock_data(..., universe=...)`, `get_stocks_response_body(..., universe=...)` with per-universe `_stocks_cache[universe]`, `get_history_response_body`, `get_top_pattern_picks`).
- `dashboard_server.py` & `api/routes.py`: HTTP endpoint handlers parsing `?universe=curated|midcap250|all_nse` on `/api/stocks`.

### Frontend Structure (`frontend/src/`)
- **Entry & Root**: `main.ts` bootstraps `AppComponent` in `frontend/src/app.ts` (`<app-shell>`).
  - **Note**: `frontend/src/app/app-root/` is unused legacy scaffold code — do not edit it.
- **Core (`frontend/src/app/core/`)**:
  - `stores/stocks.store.ts`: Singleton `stocksStore` using Angular signals (`stocks`, `activeUniverse`, `horizonStrategy`, `filteredStocks`, `loading`, `error`, `selectedSymbol`) and `loadUniverse(universe)` with `loadSeq` race protection.
  - `stores/app.store.ts`, `stores/company.store.ts`, `stores/earnings.store.ts`: Global status/quotes/ticker/bulletin and modal detail stores.
  - `services/api.service.ts`: Static & injectable HTTP client (`ApiService.getStocks(universe)`), adds `X-Stox-Request: 1` CSRF header on POSTs.
  - `services/ws.service.ts`: WebSocket client with exponential backoff + fallback polling that queries `universeProvider()` (`?universe=...`).
  - `models/`: `stock.model.ts`, `company.model.ts`, `earnings.model.ts`, `financial.model.ts`, `status.model.ts`.
  - `utils/`: `price.ts`, `verdict.ts`, `markdown.ts`, `ratio.util.ts`.
- **UI Features (`frontend/src/app/features/`)**:
  - `shell/`: `shell.component.ts`, `header.component.ts` (Watchlist / Midcap 250 / Pattern Screener tabs), `ticker-bar.component.ts`, `bulletin.component.ts`.
  - `dashboard/`: `dashboard.component.ts`, `sidebar.component.ts` (`OnPush` + signal filters), `stock-grid.component.ts`, `stock-card.component.ts` (`OnPush`), `stock-detail-modal.component.ts`, `quick-picks-table.component.ts`, `fundamental-picks-table.component.ts`, `macro-catalysts-banner.component.ts`, `portfolio-modal.component.ts`, `candle-chart.component.ts`, `sparkline.component.ts`.
  - `screener/pattern-screener.component.ts`: Pattern Screener over all analyzed NSE stocks (`/api/patterns/top`).

## 4. Key API Endpoints
- `GET /api/stocks?universe=curated|midcap250|all_nse` (returns array of stock payloads)
- `GET /api/status`, `GET /api/quotes`, `GET /api/accuracy`, `GET /api/history?symbol=&days=`
- `GET /api/patterns/top`, `GET /api/market-scanner`, `GET /api/portfolio`, `GET /api/events`
- `GET /api/company/{ticker}`, `GET /api/earnings/{ticker}`, `GET /api/financial/{ticker}/{income|balance|cashflow}`
- `POST /api/trigger`, `POST /api/add-symbol`, `POST /api/remove-symbol`

## 5. Essential Commands & Known Gotchas
- **Restart backend after Python edits**: `.\cleanup_server.ps1 -Restart` (must run outside sandbox on Windows to replace host listener on `:8765`).
- **Run backend test suite**: `.\.venv\Scripts\python.exe -m unittest discover tests` (`tests/` contains 6 test files covering deterministic engine, forensic engine, financial routes, local financials, peer benchmark, live data/security).
- **Build Angular frontend**: `cd frontend; npm run build` (strict TypeScript + `strictTemplates: true` — avoid unnecessary `?.` on guaranteed non-null properties to prevent `NG8107`).
- **Run Midcap 250 analysis**: `.\run_analysis.ps1 -Midcap250` or `.\.venv\Scripts\python.exe main.py --midcap-250`.
